# Carpeta de conocimiento

Pon aquí archivos `.md` o `.txt` con información propia de ClubÑ: preguntas frecuentes, horarios,
cómo pedir roles, normas de eventos, IPs de los servidores de juego, etc.

Cada encabezado (`# Título`) se trata como una ficha independiente. Cuando una pregunta coincide con
una ficha, el bot la usa como fuente y la cita como "documentación del servidor". Esta información
tiene prioridad sobre Wikipedia y la web.

Este archivo README.md se ignora. Los cambios se aplican al reiniciar la instancia.
